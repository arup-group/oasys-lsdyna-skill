###  Running command files from the command line

When running D3PLOT in batch it can be convenient to invoke a command file to run a specified set of commands. The following command-line arguments may be used to do this:

| -cf=  *&lt;command filename&gt;* | Runs "command filename" until its end, and then reverts to normal command line input. |
| --- | --- |
| -exit | This optional. If used then D3PLOT exits when the end of the command file is reached. |

More information about command-line syntax is given in [Appendix C](c-command-windows-file-associations.md#commandline).
