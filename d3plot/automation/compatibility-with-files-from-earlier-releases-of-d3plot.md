###  Compatibility with Files from Earlier Releases of D3PLOT

Since command-line syntax has been preserved in this version, and command input into the dialogue window is still permitted, command-line command files are backward-compatible. Button-click command files are NOT backward-compatible.

The file format used for Oasys Suite 7.0 command files is itself backwards compatible: you should not need to modify existing files at all for them to work with this version.
