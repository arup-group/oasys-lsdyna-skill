##  FAST-TCF OVERVIEW

FAST-TCF is a scripting language for T/HIS. It is designed to be editable and backward-compatible with previous versions of T/HIS. From T/HIS 9.2, FAST-TCF scripts can be recorded and played back. The FAST-TCF scripts are plain text files, and are therefore easy to edit and manipulate.
