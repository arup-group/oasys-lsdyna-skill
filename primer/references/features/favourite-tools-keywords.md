##  Favourite Tools & Keywords

As well as the default Tools and Keywords panels, users can optionally create their own panel containing a subset of these buttons. This can be used to both save vertical space in the right-hand menu panel and also make it quicker and easier to access your most frequently used features. All Keywords from Volumes 1, 2, and 3 are supported in the Favourite Keywords menu. Along with standard Tools, buttons from the Mesh Tools menu may also be added to the Favourite Tools menu. A maximum of 100 buttons can be added to each of the two Favourites menus irrespective of hierarchy levels.

![](../Storage/primer-22-1/favourite-tools-keywords-2023-02-09.png)

Buttons in the Favourite Tools menu can be linked not just to standard Tools but also to custom scripts. Buttons can also display custom text including UTF-8 characters, plus additional metadata to further explain the functionality of each button.

![](../Storage/primer-22-1/favourite-tools-keywords-2023-02-09-1.png)

Custom hierarchy levels and popups are also supported.
