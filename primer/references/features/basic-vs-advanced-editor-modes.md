#####  Basic Vs Advanced Editor Modes

The sections immediately below describe the [basic](basic-editor-mode.md#basic_editor)editor modes that have always been available in PRIMER . Version 18 introduces an [advanced](the-advanced-editor-mode.md#advanced_main)editor mode that is designed mainly for fitting complex paths. All the features of the existing basic editor have been retained for backwards compatibility, and in fact it should continue to be adequate for simple "belt on adult dummy" paths, however the advanced editor gives much mouse-driven control over the belt path.

Ticking or unticking the [ ] Advanced button switches between them. Either mode can be used, and you can swap between them at will.
