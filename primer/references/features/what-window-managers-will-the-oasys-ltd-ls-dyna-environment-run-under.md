###  What Window Managers Will Oasys LS-DYNA Environment Run Under?

Oasys Suite is developed primarily on Unix-based machines using X11. It is also developed on PCs running Microsoft Windows, but at present it requires an X11 emulator to be running on Windows-based platforms.

"Native" Windows support is being developed (slowly) and will be available at some time, as yet unknown, in the future.
