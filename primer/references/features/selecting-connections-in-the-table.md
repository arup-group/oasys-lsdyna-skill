####  Selecting Connections in the Table

![](../Storage/primer-22-1/primer_links/sect_6/connection/connection_table14.gif)If you want to select connections in the table you can clear the entire selection or select all connections using Clear or Sel all respectively. Alternatively you can use Select to pick connections from the screen or select them using an object menu.
