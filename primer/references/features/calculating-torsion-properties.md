####  Calculating Torsion Properties

![](../Storage/primer-22-1/primer_links/sect_6/cutsect/cut_sec_calc_torsion_prop.PNG)The torsion constant J of the section is not calculated by default since this a complicated and - sometimes - slow process, and for complex sections there can me more than one way of interpreting the answer.

If you want to compute J values use Calculate Torsion properties... to switch to the torsion calculation mode, which will show this alternative panel base:
