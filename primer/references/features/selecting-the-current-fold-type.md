####  Selecting the Current Fold Type

The Fold Type popup button controls the current fold type, which will be one of![](../Storage/primer-22-1/primer_links/sect_6/airbag/fold_type_popup.gif)

* [Null fold](null-fold-set-attributes-but-don-t-fold-mesh.md#nullfold)
* [Thin fold](thin-fold-perform-a-sharp-crease-fold.md#thinfold)
* [Thick fold](thick-fold-a-radiused-fold-spanning-1-element.md#thickfold)
* [Tuck fold](tuck-fold-a-thin-fold-tucked-into-the-mesh-centre.md#tuckfold)
* [Spiral fold](spiral-fold-rolling-layers-into-a-spiral.md#spiralfold)
* [Scrunch fold](scrunch-fold-compressing-a-3d-bag-to-a-flat-shape.md#scrunchfold)
* [Align fold](align-fold-aligning-nodes-on-a-fold-line.md#alignfold)
* [Scale fold](scale-fold.md#scale)
* [Translate fold](translate-fold.md#translate)
* Star fold
* Circular fold.

In this example a "thin" fold is current, but the type can be changed dynamically by simply selecting a new type with the popup menu. More information about each fold type is given in [SETS AND LAYERS](sets-and-layers-selecting-a-subset-of-the-airbag-for-folding.md). Star and circular folds are unavailable from this menu. These are selected to be created from the initial airbag start up screen. For more information on these types see [Creating and Folding a new airbag](sect_6_airbag.htm#createfromscratch).

The fold type button will toggle between the currently selected fold type and a null fold.
