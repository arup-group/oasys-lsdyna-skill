##  Editing Your Favourites Menu

| To add, remove or reorder buttons on your Favourites menu, click the Custom... button.<br> ![Empty Favourites menus](../Storage/primer-22-1/primer_links/sect_favourites/empty_favourites_menus.png) |
| --- |
| All available buttons are listed on the left of the Edit Favourite Tools/Keywords menu, where they can be selected and added to the list of Favourites on the right using the Add &gt; button. Similarly, selecting entries on the right-hand list and pressing &lt; Remove will remove buttons from the Favourites menu.<br> <br>The first four arrow buttons at the top of the right-hand list allow you to reorder selected items in the list. The left and right arrow buttons allow you to decrease or increase depth/level respectively.<br> <br>Custom button text can be assigned using the Edit button on the top left of the window. Custom scripts can be assigned by switching the Mode popup to Custom Tools (JavaScript).<br> <br>![](../Storage/primer-22-1/Screenshot%202023-07-12%20162354.png) |
| Pressing Apply will update your Favourites menu to show buttons in the order they are listed. Pressing Cancel will close the panel without making any changes to your Favourites menu.<br> <br>By default, the contents of your Favourites menus are saved to your HOME oa.conf file and will be reloaded in subsequent PRIMER sessions. You can change this by unticking the option Save Favourites settings on Apply  **before** pressing Apply .<br> <br>Additionally, if you want your Favourite Tools menu to be the default open tab instead of the main Tools panel (or Favourite Keywords instead of Volumes I & II Keywords), tick the option Set Favourites as default Tools tab before pressing Apply.<br> <br>![](../Storage/primer-22-1/favourites_save.png) |
