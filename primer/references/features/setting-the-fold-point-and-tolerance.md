####  Setting the FOLD_POINT and Tolerance

| The fold point identifies an XY coordinate through which the fold line passes. This can be defined by using PICK to screen-pick a node, or by typing in an explicit value (which is a distance down the relevant axis). For thin and tuck folds this point should lie on, or be very close to, a node; for other fold types any reasonable location may be chosen.<br> <br>Tolerance defines the tolerance margin either side of the fold line used when searching for nodes that lie on the line. You should aim to choose the smallest value that will include all nodes on the fold line. | ![](../Storage/primer-22-1/primer_links/sect_6/airbag/Image41.gif) |
