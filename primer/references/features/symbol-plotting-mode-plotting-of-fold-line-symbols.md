####  Symbol Plotting Mode	(Plotting of Fold Line Symbols)

Note that where folds slice through elements the actual fold line (ie along element edges) is shown as well as the defined fold line (ie across elements). The fold line symbol can be:

| **![](../Storage/primer-22-1/primer_links/sect_6/airbag/airbag_symbol_plotting_mode.gif)** | OFF No fold symbols are displayed; <br>CURRENT Only the current fold is displayed;<br> <br>1 TO N Displays all folds up to the current fold;<br> <br>ALL Displays all folds;<br> <br>0 DEGREE Displays all folds perpendicular to the (local) X-axis;<br> <br>90 DEGREE Displays all folds parallel to the local X-axis. |
