###  Airbag Folding Summary

  ****

The following process should be followed when folding an existing airbag mesh:

| <ul> <li>Read in a model containing airbag geometry (and possibly Origami definitions), and enter the <!-- #BeginLibraryItem &quot;/Library/primer.lbi&quot; -->PRIMER <!-- #EndLibraryItem -->airbag module by using the <a class="buttontext" href="nan" target="_top">AIRBAGS </a>buttons. </li> </ul> <ul> <li>Define an ORIGAMI or select an existing one using <a class="buttontext" href="define-origami-selecting-or-creating-an-origami-definition.md#defineorigami">DEFINE_ORIGAMI </a>. </li> </ul> <ul> <li>Set the local coordinate system if your airbag is not in the global xy plane using <a class="buttontext" href="local-system-defining-airbag-local-axes.md#localcsys">LOCAL_SYSTEM </a> </li> </ul> <ul> <li>Set the <a href="plotting-modes.md#plotmodes">plotting modes </a>that you require using the <a href="fold-plotting-mode.md#foldplotmode">Fold Plotting Mode </a>, <a href="airbag-plotting-mode-the-coordinate-system-used-for-airbag-display.md#airbagplotmode">Airbag Plotting Mode </a>and <a href="symbol-plotting-mode-plotting-of-fold-line-symbols.md#symbolplotmode">Symbol Plotting Mode </a>radio buttons. </li> </ul> <ul> <li>Set any options for the airbag folder using <a class="buttontext" href="folder-options.md#folderoptions">FOLDER OPTIONS </a> </li> </ul> <ul> <li>Define or modify folds using <a class="buttontext" href="set-foldcreating-fold-definitions.md#setfold">SET_FOLD </a>using <a href="subset-folding.md#subsetfolding">subset folding </a>, <a href="using-sets.md#sets">sets </a>and <a href="layers.md#layers">layers </a>as appropriate. </li> </ul> <ul> <li>If required position the folded bag using <a class="buttontext" href="positioning-folded-airbags.md#positioning">POSITION FOLDED BAG </a> </li> </ul> <ul> <li>Exit airbag folder by pressing <span class="buttontext">APPLY </span>. Note that other methods of exiting from this model will lose current fold definitions. </li> <li>Save the model to disk. </li> </ul> | ![](../Storage/primer-22-1/primer_links/sect_6/airbag/airbag_main_screen.gif) <ul> </ul> |
