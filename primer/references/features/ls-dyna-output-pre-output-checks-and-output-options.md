###  Ansys LS-DYNA Output: Pre-Output Checks and Output Options

| Before writing out the model in Ansys LS-DYNA keyword format the user is given a number of review functions.<br><br>
<br><br>| Pre-out | Shows the standard output options, described in detail below under <ul> <li> <a href="pre-out-general-tab.md#pre_general">General Tab</a>&#160;(Most commonly used settings) </li> <li> <a href="pre-out-options-tab.md#options1">Options Tab</a>&#160;(Further options) </li> <li> <a href="pre-out-options2-tab.md#pre_options2">Options2 Tab</a>&#160;(Yet more options) </li> <li> <a href="pre-out-compress-tab.md#pre_compress">Compress Tab</a>&#160;(Compression and binary output options) </li> </ul> |<br>| --- | --- |<br>| [Clean up](clean-up-unused.md#642CleanupUnused) | Runs the standard "Model clean up" operation to get rid of redundant items (see
[Clean-Up Unused](clean-up-unused.md#642CleanupUnused)) |<br>| [Check](model-check.md) | Runs the standard "Model Check" operation which checks all keywords. (see
[MODEL &gt; CHECK](model-check.md)) |<br>| Review | Gives a summary of typical model control options, principally \*CONTROL and \*DATABASE options. |<br><br>
<br>The Save settings to oa\_pref file button saves the various Pre-out options to the preferences. |  |
