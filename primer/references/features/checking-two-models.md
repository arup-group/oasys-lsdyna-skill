###  Checking Two Models

![](../Storage/primer-22-1/primer_links/sect_3/images/check_112.GIF)

If two models are in memory, a reference model can be loaded. Model check will then apply to both models and two check trees will be displayed with the reference model on the rhs.

The differences between the trees are highlighted in grey. In Diff only mode, only the differences are shown.
