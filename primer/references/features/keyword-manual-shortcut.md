###  Keyword Manual Shortcut

On some panels (Current Menu panel, Keyword Editor and Create/Edit panels, see
[Keywords](keywords.md) for more details) a [ **K** ] button (on a red background) will give access to the Ansys LS-DYNA keyword user's manual. It will open in a default pdf viewer at the volume and page corresponding the current panel. Note that the default pdf viewer and the command used to open at a specific page can be controlled via preferences, see [Appendix M](m-summary-of-oa-pref-command-line-and-environment-variable-settings.md#dialoguecommands) .

The Ansys LS-DYNA keyword user's manuals and the look up file used to determine the correct page to open at will be added to the appropriate directories upon installation. If, however, the keyword manual shortcut button does not appear please contact your local distributor or Oasys Ltd Support.
