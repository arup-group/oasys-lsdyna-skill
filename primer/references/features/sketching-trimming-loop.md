#### Sketch trimming loop (IGA_1D_BREP)

Individual trimming loops can be sketched via the Sketch option in the Modify panel for IGA\_1D\_BREP. To sketch multiple trimming loops (IG1B) simultaneously, use the Sketch option in the IGA\_1D\_BREP docked panel and select multiple IGA\_1D\_BREP definitions. To view curve labels present in IGA\_1D\_BREP definitions, tick Show curve label. To draw all IGA\_1D\_BREP trimming loops in a definition click Sketch all in the docked panel or go to Entity panel-&gt;IGA-&gt;Drawn for IGA\_1D\_BREP.
