##  Appendix E: Seatbelt "Tree" File Structure

A seatbelt definition is not a special file, rather it is an ordinary Ansys LS-DYNA input deck to which an extra section has been added after the \*END card which allows PRIMER to recognise and manipulate seatbelt data.
