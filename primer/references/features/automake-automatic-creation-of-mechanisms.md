####  Automake: Automatic Creation of Mechanisms

From PRIMER 11 onwards you can also create mechanisms automatically using the kinematic properties of the Ansys LS-DYNA model, this process [is described below](automake-creating-mechanisms-automatically.md#automake). An automatically created mechanism is exactly the same as one created manually, and can be edited and processed in same way.
