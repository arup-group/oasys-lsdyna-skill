####  Additional Options for Connections

![](../Storage/primer-22-1/primer_links/sect_3/images/mod_conx.PNG)

Properties If active, all properties available on connection table will be calculated for each pair of matched connections. Any connections for which properties differ will be reported on the tree.

Tolerance is the spatial tolerance to be used while matching connections
 ![](../Storage/primer-22-1/primer_links/sect_3/images/conx_comp_9.bmp) 
For connections with property differences, the Conx -&gt; table function will give a detailed description.

![](../Storage/primer-22-1/primer_links/sect_3/images/conx_comp_2.png)

For detailed use of connection compare table, see [Connection Compare](connection-compare.md#conx_comp)
