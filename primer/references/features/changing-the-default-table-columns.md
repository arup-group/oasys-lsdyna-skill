####  Changing the Default Table Columns

By default the connection table will show the Connection ID, type and subtype, Part, Diameter, 3 layers, status error and error details columns. If you want to change which columns are shown by default then [change the columns shown](changing-the-table-columns.md#changetablecolumn) to be the ones you want and press Save Settings in the View... popup. This will automatically add a preference primer\*conx\_table\_columns to your home oa\_pref file with the appropriate columns.
