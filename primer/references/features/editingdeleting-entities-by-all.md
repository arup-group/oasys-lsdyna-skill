Each of the existing rows can be modified if needed. For each row the [ADD/REMOVE](adding-entities-by-all.md#alladd)and  [box](adding-entities-by-all.md#allbox) buttons work in the same way as the [panel to add entities by all](adding-entities-by-all.md#addall).
