####  Adding a 'list' row using the group editor

A new entry can be added to the group by using the ADD\_ROW button. The  [ADD](adding-entities-by-list.md#listadd)  [/ REMOVE](adding-entities-by-list.md#listadd)and  [box](adding-entities-by-list.md#listbox) buttons work in the same way as the [panel to add entities by list](adding-entities-by-list.md#addlist). As an example we will add the row to the group 'Remove PART 500'. At present the ADD\_ROW button is inactive as there is nothing to add. Firstly, the [Add/Remove popup](adding-entities-by-list.md#listadd)must be used to change the ADD button to REMOVE .

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6h.gif)

Next the part needs to be selected. You can either type the part number into the box or (as shown) use the popup menu to select the part from a list or pick it from the screen.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6i.gif)

| Now a part has been selected the ADD\_ROW button becomes live.<br> <br>![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6j.gif) |
| --- |

Now to add the row to the group simply press the ADD\_ROW button. A new row '3' will be added to the list. The add row will be reset back to the default values.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6k.gif)

####  Editing a 'list' row using the group editor

Each of the existing rows can be modified if needed. For each row the [ADD/REMOVE](adding-entities-by-list.md#listadd)and  [box](adding-entities-by-list.md#listbox) buttons work in the same way as the [panel to add entities by list](adding-entities-by-list.md#addlist). An entity can be removed from a row by either deleting the number in the text box or by using the REMOVE option on the popup. For example to remove part 10, right click on 10  to bring up the popup menu and select REMOVE.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6l.gif)

| The part will be removed from the row (see image below). To save the change into the group press END\_EDIT.<br> <br>![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6m.gif) |
| --- |

####  Deleting a 'list' row using the group editor

To delete an entry from a group use the Delete row? popup. For example, to remove entry/row 2right click on the 2 button and select DELETE ROW from the popup menu.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6n.gif)

The row is deleted and the remaining entries are moved up the list.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_6o.gif)
