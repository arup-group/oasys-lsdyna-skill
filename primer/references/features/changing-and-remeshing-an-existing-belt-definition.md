####  Changing and Remeshing an Existing Belt Definition

Once a seatbelt has been created and meshed in PRIMER , (ie that there is a set of \*BELT cards after \*END) then you can do the following:

| Remesh the existing path geometry using a different mixture of elements. <br> <br>For example change an existing Mixed 1D/Shell belt to a Mixed 2D/Shell belt. | Simply use Mesh to define a new arrangement of elements or element types. <br> <br>Note that simply remeshing does not, in itself, permit the following: <br> <ul> <li>Changing the basic belt path </li> <li>Changing the number of rows of elements across the belt, or any other aspect of the belt element geometry. </li> </ul> <br> <br>The existing belt definition will be deleted and the new one will replace it. <br> <br>(If you have not previously "Fitted" the belt during this PRIMER session it will be necessary to do that first, since the detailed meshing path is not stored in the keyword file. Performing a "Fit" will repeat the form-finding operation using the saved basic path, which regenerates a detailed path suitable for remeshing.) |
| --- | --- |
| Modify the basic belt path, or change the belt geometry, and then remesh. | Firstly use Fit , where you can: <br> <br> <ul> <li>Define a new belt path by adding, subtracting or moving path points. </li> <li>Change the belt dimensions or number of row </li> </ul> <br> <br>Once the revised path geometry is correct Save it, re- Fit the belt to the dummy, Accept the result, and then re- Mesh it as above. The existing definition is deleted and a new one created as before. |
| If the dummy has moved, and you want to refit the existing belt definition to it in its new location. | The  [Auto-refit](auto-refit-refitting-a-belt-automatically-when-the-dummy-moves.md#refit) capability will perform this task if no other changes are required to belt organisation or topology. Auto-refit attempts to re-use all existing node, element and set labels so that the belt just appears to move to the new location. <br> <br>Otherwise the process may be performed manually as above. |
