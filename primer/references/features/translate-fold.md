####  Translate Fold

![](../Storage/primer-22-1/primer_links/sect_6/airbag/translate_fold_button.gif)

| ![](../Storage/primer-22-1/primer_links/sect_6/airbag/translate_fold.gif)The translate fold is used for moving parts of the origami.<br> <br>The translation is done in the local co-ordinate system of the fold, NOT the global co-ordinate system.<br> <br>To help you visualise the local co-ordinate system the axis triad is drawn on the airbag.<br> <br>The local axes can be changed using the LOCAL SYSTEM . The fold point (local axes origin) can be changed by selecting a new Fold point. See the examples for the scale fold as the method is identical.<br> <br>The nodes/elements that you want to translate are selected in the normal way using sets and layers as required.<br> <br>You can translate the airbag by one of 3 methods:<br> <ol> <li>You can type in separate X, Y and Z distances in the text boxes.</li> <li>You can pick 2 nodes using&#160;<span class="buttontext">Pick N1 -&gt; N2&#160;</span>to define the distance.</li> <li>You can drag the selection interactively using&#160;<span class="buttontext">DRAG</span>.</li> </ol> |
| --- |
| ![](../Storage/primer-22-1/primer_links/sect_6/airbag/translate_fold_during_drag.gif)Press DRAG. The window will change as shown on the right. All other functions are unavailable while dragging. <br>Click and drag with the mouse and the selection will be moved on the screen and the distance boxes updated. When the mouse button is released the screen will be redrawn. Make sure the Fold type button is toggled to show the translate fold type (not the null fold type) or you will not see the translation!<br> <br>You can only drag in the XY plane of the fold. You can continue dragging the selection until you are satisfied.<br> <br>You can cancel dragging at any time by pressing ABORT DRAG.<br> <br>You can start dragging again (undoing the last drag you made) by pressing UNDO DRAG.<br> <br>To finish the drag operation press APPLY DRAG. The distances will be saved. |
