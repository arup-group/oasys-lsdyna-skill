###  Measure Beams Orientation

![](../Storage/primer-22-1/primer_links/sect_6/dummies/fig_8_1.gif)This option gives you the ability to obtain positioning information for a dummy model by measuring the orientation of internal BEAM elements with respect to the XY/YZ/ZX planes.

The **Measure** panel provides a list of BEAM PARTs in the model with these (optional) filters:

* One BEAM per Part if turned on PRIMER will just display parts which only contain one beam.
* Text Filter - Filter the list of PARTs by PART title string using wildcard syntax containing "\*" and "?" - where "\*" is replaced with any character string and "?" with any single character.
