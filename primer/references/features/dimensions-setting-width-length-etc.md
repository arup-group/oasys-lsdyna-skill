####  DIMENSIONS Setting Width, Length, etc

| ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_3c.png)The dimensions of a belt are:<br> <br>#rows : The number of (shell) elements across the width.<br> <br>Width: The total width of the belt. (For #rows &gt;0 each shell is Width / #rows wide.)<br> <br>Thickness: Shell element thickness.<br> <br>Length: Characteristic element length (both seatbelt and shell elements).<br> <br>Clearly the first three refer only to belts that include shell elements. If #rows =0 then the belt becomes seatbelt elements only. |
