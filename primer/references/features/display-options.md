###  Display Options

Several options are available for changing the display:

*Show Input Points - Toggles whether the inputs are drawn* :

![1](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_07.png)

*Text - Allows you to select whether the input values/names are displayed (or both).*

![2](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_08.png)

*Text Size - Allows you to change the size of the text drawn in the graphics window. Note: this is dependent on screen resolution; some resolutions may require double clicking of the arrows.*

*Show Perimeter - Toggles whether the perimeter is drawn* :

![3](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_09.png)

*Coloured Input - Toggles whether the input values are displayed as large tri-colour blobs or small blue squares* :

![](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_10.png)

Y-Offset - This applies an offset to the y-coordinate of the displayed data it is useful when displaying multiple plots in the same session.

Change Symbol Size - Changes the size of the drawn data (input/output and perimeter).

Show Plot - Shows and hides the graphics plotting entirely (useful when working with multiple data sets).

Show Contour Bar - To show and hide the contour bar.

Toggle Mode - For use when displaying multiple plots via multiple HIC Area Calculator panels. The toggle button will set the display so that only the data from the session from which the button was pressed is visible. It will also map the display options from the selected session to any others. While active, you can toggle between plots using the left and right arrow keys on the keyboard. An orange border highlights the currently visible data.

![](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_30.png)

Project to Mesh - Can be used to project the calculated values from the z=0 plane to a mesh:

![](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_13.png)

**Note on output display mode:**

When showing the calculated values (the colourful contour plot made up of lots of dots), it is possible to turn on/off contour bands by clicking the colours in the contour bar.

![](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_14.bmp)
