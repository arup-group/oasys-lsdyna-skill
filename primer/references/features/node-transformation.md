###  NODE_TRANSFORMATION

Node transforms can be created and/or modified.

![](../Storage/primer-22-1/primer_links/sect_5/n_trfm/create_ntfrm.png)

Select or create the TRSID, refer to [Edit of Include Transform](edit-of-include-transform.md#editincltrans) for more information. The node set ID can also be selected or created using the usual methods.

####  Suspending node transforms

| Sometimes it may be useful to suspend node transforms. The Suspend option on the Node transform menu allows you to do this. <br>Transforms can be suspended/reinstated by clicking on them in the menu. If a transform is currently suspended it is shown in red (e.g. M1/N\_TR1 is currently suspended in the right hand figure). | ![](../Storage/primer-22-1/primer_links/sect_5/n_trfm/suspend_ntfrm.png) |
