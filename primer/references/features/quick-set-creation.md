####  Quick Set Creation

| The **QUICK SHELL SET** button allows you to create a shell set in a much quicker way than the normal creation method.<br> <br>A shell set is automatically created for you with the next free label. | ![](../Storage/primer-22-1/primer_links/sect_6/airbag/quickset.gif) |
| --- | --- |

Shells can be added or removed from the set by the following methods

1. Clicking and dragging with the left mouse button will add shells to the set by box. 
2. Multiple left mouse button clicks will add shells to the set by polygon. 
3. Clicking and dragging with the right mouse button will remove shells from the set by box. 
4. Multiple right mouse button clicks will remove shells from the set by polygon

| To finish selecting the shells and create the set, press the APPLY SELECTION button. <br>When selecting by polygon, if you close the polygon by clicking back onto the first point, the shells will be added.<br> <br>Alternatively you can press CLOSE POLYGON to select the shells. REJECT LAST PT will delete the last point in the polygon. ABORT POLYGON will restart the polygon. | ![](../Storage/primer-22-1/primer_links/sect_6/airbag/quickpick.gif) |
