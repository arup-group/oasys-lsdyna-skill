# Themes for the Graphical User Interface

3 themes are available for Oasys LS-DYNA Environment software. Users can select a **Light**, a **Dark** or a **Classic** theme. The latter uses the colours of the old user interface (used prior to version 17 of the software).

The themes offer different colour and contrast options for comfort and accessibility.
