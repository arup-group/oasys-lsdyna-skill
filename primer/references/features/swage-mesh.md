###  Swage Mesh

| The swage mesh allows you to easily create swages/beads in shell meshes by selecting points on a Shell or a Shell Node.<br> <br>The swage panel shows the section view of the intended swage mesh and explans the basic parameters required to create the swage mesh.<br> <br>You can also adjust any of the parameters if required. When you are happy with the properties pressing Sketch will see a preview of the mesh that PRIMER will create. <br> Outline will only show the outline of the proposed mesh. <br> Auto Update is a toggle button that automatically updates the sketch of the swage mesh whenever any of the swage mesh parameters or the options values are changed. <br>To actually create the swage and remesh press Apply .<br> <br>Pick pts. is the toggle button to switch ON/OFF the points selection to define the path of the swage on the shell mesh.<br> <br>Auto PID automatically takes the PART ID of the new swage mesh from the shell element on which the first swage path point is selected.<br> <br>The swage mesh is created along the NORMAL direction of the shell elements on which the swage path points are selected. <br> Reverse button reverses the direction of the swage.<br> <br>Element Pitch is the element size along the length of the swage path. <br> <br> Auto El. Size button automatically sets the mesh element sizes for the swage mesh as the "average" element size of the original shell mesh.<br> <br>The SIDE ends of the swage mesh can be three different types of shapes:<br> <br><br>| CHAMFERED  <br> <br> ![](../Storage/primer-22-1/primer_links/sect_6/meshing/swage_chamfered.png) | SLANTED  <br> <br> ![](../Storage/primer-22-1/primer_links/sect_6/meshing/swage_slanted.png) | VERTICAL  <br> <br> ![](../Storage/primer-22-1/primer_links/sect_6/meshing/swage_vertical.png) |<br>| --- | --- | --- |<br><br> <br>Also the SIDE surfaces for the swage mesh can be created with these two methods:<br> <ul> <li>FREE: Creates a free shell mesh using average element sizes specified for the side edges. </li> <li>STRUCTURED: Creates a regular shell mesh with well defined edges along the side surfaces. <a href="offset.md#offset"> </a> </li> </ul> <br>The original shell mesh is remeshed up to the distance from the swage mesh defined by Remesh Distance. <br> <br> The remeshed shells selection is restricted by break angle between normals of the adjacent shells defined by the Break Angle . <br> <br> Add Remesh and Remove Remesh can be used to alter the selection of shells to be remeshed on the original shell mesh if required. <br> <br>The element size for the remeshed shell mesh is defined by Remesh Length .<br> <br>Save Settings button saves the current parameters and options values defined in the swage mesh panel to the preferences file. |
