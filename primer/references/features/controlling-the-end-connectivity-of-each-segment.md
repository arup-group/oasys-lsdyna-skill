####  Controlling the End Connectivity of Each Segment

| By default PRIMER generates any nodes required at the end of each segment, ensuring that connectivity between stretches of belt is maintained. Also if a slipring or retractor are specified at the end of a segment this will also be created.<br>
<br>However it is possible to override this behaviour and to specify existing nodes, sliprings and retractors at the ends of segments, and this might be necessary when connecting up a belt meshed in PRIMER to one meshed elsewhere that the belt fitter does not "know" about. | ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_4i1.png) |
| --- | --- |
| NODE: defining the end node for 1D seatbelt element connectivity <br>When a segment ends in a 1D seatbelt element the end node is normally created or selected automatically, but you can override this by choosing Existing and specifying an existing node.<br> <br>In this case it is your responsibility to ensure that connectivity between adjacent stretches of belt is correct. | ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_4i2.png) |
| SLIP or RETR: defining a slipring or retractor (1D and 2D cases) <br>![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_4i3.png)In a similar way if a slipring or retractor have been defined at the end of a stretch of belt PRIMER will normally create them automatically, however you can override this and select an existing element.<br> <br>Note that:<br> <ul style="font-size: 14.6667px;"> <li>In the 1D case any existing seatbelt elements will be replaced as required with new elements created as part of this meshing operation, and will be left &quot;floating&quot; in the model. You will need to delete these manually.<br><br>The slipring or retractor node (SBRNID) will be replaced with the correct node for this mesh. This may result in the slipring / retractor moving in space in order to be at the correct position.<br><br><br></li> <li>In the 2D case any existing element sets will be emptied of their contents, and new elements from this meshing operation inserted. Again you will need to tidy up any elements left &quot;floating&quot; in the model.<br><br>Any existing node set (-SBRNID) will be emptied and repopulated with new nodes at the correct positions. As in the 1D case this may result in the slipring/retractor moving to a new location.</li> </ul> |

###### Meshing with "meshed" (radiused) sliprings 
When a meshed (radiused) slipring has been specified PRIMER will show SLIP as being specified at that point, and also a label. However during the actual meshing stage no explicit slipring will be created, rather the belt elements will be continuous around the specified radius. Therefore no special action is required for these sliprings. [Previous](how-the-ends-of-stretches-of-shells-or-2d-seatbelts-are-handled.md)  |  [Next](navigating-the-meshing-panel-between-segments.md)
