# Introduction

This tool enables you to quickly create seat mechanisms and position the seat at various predefined points along the seat track, in accordance with different testing protocols. Specify part sets, node sets, and connection nodes, which are used to build mechanisms such as seat slider, height adjustment, base tilt, and headrest movement.

The seating positions are determined based on track curve points provided via file input (.iges or text file) or model selection. Once configured, you can easily visualise and position the seat according to different regulatory or design requirements
