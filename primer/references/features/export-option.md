###  Export Option

| Step 1  <br>The Export option allows you to write out nodal coordinates and initial stress data for parts in the seat.<br> <br>There are three steps to follow to write out the data:<br> <br>First select the name of the file that you want to write by either typing the name in the textbox or using the file selector.<br> <br>Once done, press Next .<br> <br><br> ![](../Storage/primer-22-1/primer_links/sect_6/seatfoamcompression/export1.gif) |
| --- |

| Step 2  <br>Second, select the parts that you want to write to the file.<br> <br>PRIMER Will show an object menu allowing you to select the parts you want. All of the normal options for object menus will be available. For example, if the seat is in an include file it may be helpful to first filter by include file so that only the parts for the seat are shown. Then if you only want to write out the data for the solid parts you could then additionally filter by element type SOLID or by a material type to further limit what is shown in the object menu.<br> <br>Once all of the required parts are selected press Next .<br> <br><br> ![](../Storage/primer-22-1/primer_links/sect_6/seatfoamcompression/export2.gif) |
| --- |

| Step 3  <br>Now select what you want to write to the file by using the checkboxes. <br>A basic file could just contain the nodal coordinates. This could also be used as a way of undoing a seatsquash. If you save the coordinates of the seat foam nodes before doing a seatsquash you can [import](%28DEFINE_%29%20CURVETABLE%20%20Defining%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20Load%20Curves..html#import)them again if required to 'undo' the seatsquash.<br> <br>When you have the categories you want selected press Apply to write the file. Finally, it is possible to save settings by using the button Save settings to oa\_pref file .<br> <br>To continue press Apply and Finish .<br> <br><br> ![](../Storage/primer-22-1/primer_links/sect_6/seatfoamcompression/export3.gif) |
| --- |

| Step 4  <br>When the file has been written press Finish .<br> <br><br> ![](../Storage/primer-22-1/primer_links/sect_6/seatfoamcompression/export4.gif) |
| --- |
