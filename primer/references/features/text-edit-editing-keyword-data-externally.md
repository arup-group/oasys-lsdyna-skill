###  Text Edit Editing Keyword Data Externally

You can export data to file in keyword form and then use a system text editor to view, modify and update one or more keywords. This also gives the ability to import data from other decks by "cut and paste" into the text editor session and then import back into
PRIMER
. Embedded keyword comments can also be visualised and edited using this capability.
