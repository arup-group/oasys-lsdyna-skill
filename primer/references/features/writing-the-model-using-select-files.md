####  Writing the Model Using Select Files

To save the model once it has been built, in the main menu right click on Model and select write in the pop-up.

| In the [Write to file](model-write.md#33MODELWRITE) window input the name you wish to save the master file under in the input box:<br><br>![](../Storage/primer-22-1/primer_links/sect_3/images/fig_3_3_1.png) |
| --- |

| Select appropriate options in the [Pre-Output check](ls-dyna-output-pre-output-checks-and-output-options.md#precheck) window:<br>
<br>![](../Storage/primer-22-1/primer_links/sect_3/images/fig_3_3_2.gif) |
| --- |

| If you select Master File only mode and any include files have been renumbered during the build process PRIMER will prompt you to change to Select files mode, where the renumbered includes will be preselected, putting up the following panel.<br>
<br>![](../Storage/primer-22-1/primer_links/sect_3/images/keyout_presel.gif) |
| --- |

| SELECT\_FILES will then take you to the keyout selected panel.<br>
<br>![](../Storage/primer-22-1/primer_links/sect_3/images/keyout_presel2.gif)<br>
<br>Note - PRIMER stores a marker that the component has been renumbered, this is **not**a rigorous check for modified includes. To achieve that you need to use the compare to disk function described above. |
| --- |
