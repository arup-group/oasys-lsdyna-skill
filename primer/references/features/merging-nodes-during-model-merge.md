###  Merging Nodes During Model Merge

If the Merge nodes after merging model checkbox on the main model merge panel is selected then PRIMER will perform a [node merge](merge-nodes.md#mergenodes) on the target model after the models are merged together.

The [merge nodes](merge-nodes.md#mergenodes) panel is started in a special mode where only nodes from the secondary model can be replaced by nodes from the primary model. In this mode:

* The node label from the primary model is always retained.
* The position of the merged node will always be the position of the node in the primary model.

For more details on merging nodes see the [merge nodes](merge-nodes.md#mergenodes) section of the manual.
