##  MESHING

PRIMER has some simple meshing facilities. The options available under the Meshing tool are:

| Mesh | [Simple meshing facilities](simple-meshing-operations.md#simpleMesh)such as [extrude](extrude.md#extrude), [offset](offset.md#offset), [ruled surfaces](ruled.md#ruled), [plates](plate.md#plate)etc |
| --- | --- |
| Split | [Split shells](element-defining-structural-elements.md#splitshell) |
| Create hole | [Create a hole](create-hole-in-mesh.md#createHole)in an existing mesh |
| Remove hole | [Remove a hole](remove-hole-from-mesh.md#removeHole)from an existing mesh |
| Remesh area | [Remesh an area](remesh-area.md#remeshArea)of existing mesh |
| Cobweb mesh | Create a [cobweb mesh](cobweb-mesh.md#cobwebmesh)on an existing mesh |
| Morph | [Morph](mesh-morphing.md#mesh_morphing)a mesh |
| Tet mesh | Create a [tetrahedron mesh](create-tetrahedron-mesh.md)inside a closed volume of shells |
| Geometry | [Mesh geometry](mesh-geometry.md#meshGeometry)surfaces |
