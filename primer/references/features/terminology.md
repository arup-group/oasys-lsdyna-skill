####  Terminology

Various areas of this panel are referred to below:

| **The Acronym row**: One or more rows of headers showing the acronyms for each field. | ![](../Storage/primer-22-1/primer_links/sect_5/5a/kwe_arow.png) |
| --- | --- |
| Hovering the mouse over a button will give more information about the data. Clicking on a button (other than Options... ) will sort the data rows by that column. |
| **The Entry row**: One or more rows on a green background to enter new data. | ![](../Storage/primer-22-1/primer_links/sect_5/5a/kwe_entry.png) |
| This row will initially be blank: you must type in or select data to populate it, then use Create to create the definition and store it in the database. |
| **The Data rows:** Rows of existing data on a blue background. | ![](../Storage/primer-22-1/primer_links/sect_5/5a/kwe_data.png) |
| Entries in these fields can be edited by over-typing them or by selecting new values from popup selection menus.<br> <br>Multiple rows may be edited simultaneously by selecting the rows and then changing the required data field on any row to propagate its change to all other selected rows. |
