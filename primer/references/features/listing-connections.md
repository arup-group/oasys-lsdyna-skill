####  Summary or detailed listing

When you select connections to list you can choose how connections are listed. The options are either  [Detailed](listing-connections.md#detailed) or  [Summary](airbag-folding-summary.md#summary).

![](../Storage/primer-22-1/primer_links/sect_6/connection/list_weld_2.gif)

####  Summary listing

In summary listing PRIMER shows how many connections tie 2, 3, 4... panels together. This is useful as a quick check. If you know that the maximum number of panels that you weld for any spotweld is 3, and there is a 4 noded weld then there is an incorrect weld.

![](../Storage/primer-22-1/primer_links/sect_6/connection/list_weld_summary.gif)

####  Detailed listing

In detailed listing PRIMER shows the coordinates and panels of each connection. The format of the listing is similar to a PRIMER connection file.

![](../Storage/primer-22-1/primer_links/sect_6/connection/list_weld_detailed.gif)
