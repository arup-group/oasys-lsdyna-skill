###  Points Tab

The points tab contains settings for editing the HIC data.

![](../Storage/primer-22-1/points-tab/points-tab-2024-04-09.png)

####  Point Shown Filter

Allows you to show and hide different types of input point based on the first letter of their name:

* C = Child
* A = Adult
* B/W = Cyclist

![](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_17.bmp)

Any subsequent calculations will only be for the displayed data.

####  Edit Point - Single & Multi

The Edit Point options allows you to edit the HIC value of a point (or multiple) by simply clicking it and typing in a new value. Area and scores are recalculated using the updated data value(s). This is useful for analysing 'what if' type scenarios.

####  Edit Point - Name

The Edit Name option allows you to edit the name of a point. **Note: the tool does not currently check for duplicate point names, it is your responsibility to ensure point names are unique.**

####  Point Offset/Scale

The Offset/Scale Point option allows you to offset or scale HIC points.

![](../Storage/primer-22-1/primer_links/sect_6/pedestrian_markup/hic_area_19.bmp)

If the entry is between 0 and 5 it is applied as a scale factor. If the entry is greater than 5 or less than 0 it is applied as an offset.

####  Reflect Points

Reflect points about a chosen axis (global X, Y, Z). Points that are reflected will have \_R appended to their name.

####  Delete Point(s)

The Delete Point(s) option allows you to delete points from the HIC plot.

####  Restore Blob Plot 
 
The 'Restore Blob Plot' button reverts the data back to the form read originally. Any point edits or combinations are lost.

#### Query Point Data
 
Query Point Data allows you to select a point and have a pop up show you the main inputs (e.g. X, Y, Z position).

#### Open Directories
 
For points that have valid paths input, the Open Directories button will open a file browser window for the directory where the data is located.
