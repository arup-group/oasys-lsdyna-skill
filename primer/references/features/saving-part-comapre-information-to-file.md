###  Saving Part Compare Information to File

The information in the part compare table can be saved to a xlsx spreadsheet. Click on the 'Write' option to get the below menu where you can specify the filename. There is an option to write images of the parts referenced in the compare table. You also have an option to change the background colour to white when capturing the images. You can also change the height and width of the images in pixels to a suitable value (it is best to create a smaller image here to avoid large images ending up in your spreadsheet).
