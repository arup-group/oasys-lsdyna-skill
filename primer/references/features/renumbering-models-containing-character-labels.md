####  Renumbering Models Containing Character Labels

If a model contains character labels then they will not be included when renumbering using the main [Renumber contents](renumber-contents-renumbering-the-item-labels-within-a-model.md#371RENUMBERCONTENTS) panel.

However they can be viewed changed/renumbered etc using the [individual category](renumber-contents-renumbering-the-item-labels-within-a-model.md#Torenumberanindividualcategoryselectively) panel. e.g. the following figure shows the renumbering panel for a model that contains materials with character labels.

![](../Storage/primer-22-1/primer_links/sect_5/5a/renumber_clabel.gif)

If the category contains character labels then the Range to renumber section will have an additional option, Integer items . If ALL items is selected then the character labels will be included in the renumbering. If Integer items is selected then they will not be included.
