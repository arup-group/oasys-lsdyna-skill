####  Good Basic Path Creation Practice

| *Use as few points as possible.* | Extra points are usually unnecessary, and can cause curvature problems: 4 or 5 per segment is plenty. |
| --- | --- |
| *Basic path shape is not critical* | The basic path does not need to follow the dummy shape exactly: a "loose" initial fit giving good curvature will be quite satisfactory. |
