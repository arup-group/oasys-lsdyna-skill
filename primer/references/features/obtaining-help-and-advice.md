##  Obtaining Help and Advice

PRIMER has extensive on-line help available. In any context you will find either a HELP button or a [ **?** ] (on a green background) that will give access to help. Generally speaking it will map a "Help Box", as shown in the example below, and input will be locked into that box until you click on OK (or hit &lt;return&gt; in that box). The Manual button links to the appropriate page of the on-line version of this manual.
