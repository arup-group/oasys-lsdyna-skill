# Final Seat and Output

## View and Position Seat Configurations

After performing multiple seat positionings, you can visualise them by selecting the regulation next to “Select Regulation” and choosing the relevant position from the dropdown. Click Position Seat to view the positioned seat.

![](../Storage/primer-22-1/seat-pos-final-seat-and-model-output/seat-pos-final-seat-and-model-output-2025-04-28.png)

## Model Write-Out

![](../Storage/primer-22-1/seat-pos-final-seat-and-model-output/seat-pos-final-seat-and-model-output-2025-04-28-2.png)

Select the appropriate model write method — “1: Save all positions in a single seat model” or “2: Write separate models for each position” — to save the positioned seat model.

* Select method 1 to store all positions in the seat model and use Read a Model with Stored Positions available on the main input panel to visualize the positioned seat.![](../Storage/primer-22-1/seat-pos-final-seat-and-model-output/seat-pos-final-seat-and-model-output-2025-04-29.png)
* Select method 2 to write out individual models for each seat position.
