###  Check XML File

![](../Storage/primer-22-1/primer_links/sect_3/images/check_114.gif)

The contents of the check tree may be saved to an xml file using Write xml on the check tree.

Instead of reading in and checking a reference model for comparison we can simply load the (previously saved) xml file using the reference file option. This is particularly useful if working with **v** **ery large models** where the time required to read and check the reference model is considerable and the memory required to hold two large models in PRIMER may not be available.
