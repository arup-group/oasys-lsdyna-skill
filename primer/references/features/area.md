####  Area

Area allows you to mesh a quadrilateral or triangular area. Use the popup to choose which type to mesh.

Pick the 3/4 corner nodes for the mesh. Currently, for a quadrilateral mesh the number of shells between N1and N2 must be the same as between N3 and N4, and the number of shells between N1and N4 must be the same as between N2 and N3. For a triangular mesh the same number must be used for all sides.

Give either the number of shells to create or the size of shells to create, in which case PRIMER will determine the number required.
