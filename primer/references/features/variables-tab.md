####  Variables Tab

The Variables tab controls \*MORPH\_FLOW definitions and design variable files, which can be used to parametrise morphing.

A morph flow is a list of morph points, each with an assigned vector. When a design variable is applied these vectors are multiplied by a variable value (specified later), the corresponding morph points are then displaced by these vectors. The morph flow definition also contains:

* a unique name used to identify it from the command line
* information about variable ranges. This has been added for future development only and is not currently used.
