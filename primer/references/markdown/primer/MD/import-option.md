###  Import Option

| Step 1  <br>Once the analysis is finished, read your original model, in which dummy and seat foam components have penetration.<br> <br>Go back to the Seat squash panel, click on the Import button and read in the dynain file that Ansys LS-DYNA has written out. This file contains the final geometry and initial stress data of all the **DEFORMABLE** parts that you define at **STEP 4.**<br> <br>To continue press Next<br> <br><br> ![](../Storage/primer-22-1/import-option/import-option-2025-08-26.png) |
| --- |

| Step 2  <br>PRIMER will then read the file into a temporary model.<br> <br>Either read the data for All nodes in dynain file, All parts in dynain file or Select parts to choose the parts in the dynain file to read data from<br> <br>To continue press Next<br> <br><br> ![](../Storage/primer-22-1/import-option/import-option-2025-08-26-1.png) |
| --- |

| Step 3  <br>Select the features that you want to initialise. (Initial stress). Finally, it is possible to save settings by using the button Save settings to oa\_pref file .<br> <br>To continue press Apply and Finish .<br> <br>The seat foam components are now in their compressed state and the contact between seat and dummy is de-penetrated.<br> <br><br> ![](../Storage/primer-22-1/import-option/import-option-2025-08-26-2.png) |
| --- |
