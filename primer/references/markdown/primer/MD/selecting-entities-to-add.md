####  Selecting Entities to Add

The following example shows how to add a range of entities to a group. We want to add 'Parts between 1 and 45 that are in box 1'. 
First [select the box](using-a-box.md#rangebox)as described above and choose [ADD or REMOVE](selecting-add-or-remove.md#rangeadd)(in this example we want to add parts).

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7c.gif)

| A start and end range must be given. You can either type the numbers into the boxes or use the standard PRIMER object menus to select the part or pick it from the screen. For example right clicking on the From field:<br> <br>![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7d.gif) |
| --- |

When the part is selected/picked (in this example part 1 is picked) the from field is filled in.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7e.gif)

| Similarly, the to field can be selected.<br> <br>![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7f.gif) |
