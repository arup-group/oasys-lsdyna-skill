####  Orienting the Whole Path

| ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_2j.gif)It can be convenient to move the whole path as a single entity, for example when refitting an existing belt path to a dummy definition that has moved.<br>
<br>Therefore it is possible to apply the standard PRIMER orientation functions to the points that make up the path. |
| --- |

#### 

The transformations are self-explanatory, and usage is similar to that of the main ORIENT commands, with the exception of the treatment of fixed and end points. The TRANSLATE variant is used in this example, but it applies equally to the other modes.

| By default only unfixed points are moved, but you can choose to move end and/or fixed points as well.<br> <br>MOVE\_ENDS Allows end points to move<br> <br>MOVE\_FIXED Allows all fixed points to move. | ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_2k.gif) |
| --- | --- |

Paths can be oriented by typing in transformations, or DRAGged with the mouse. Dragging uses the same &lt; *mouse button* &gt; vs &lt; *orientation axis* &gt; arrangement as modifying single points: left button is X axis, middle Y and right Z.
