## POV-Ray

POV-Ray is the "Persistence of Vision" Ray Tracing software package. Oasys LS-DYNA Environment can export files for this and use it to produce ray-traced images. We wish to acknowledge the efforts of the custodians of the software and thank them for making it freely available, enabling us to provide this capability.

POV-Ray is freeware that is licensed under the GNU AFFERO GENERAL PUBLIC LICENSE Version 3, 19 November 2007 which may be found here [http://www.povray.org/povlegal.html](http://www.povray.org/povlegal.html). This grants "unlimited permission to run the unmodified program" so there are no restrictions placed on users.

However that licence places certain restrictions on software which might embed it or use its source code, also on its redistribution, therefore :

* Oasys LS-DYNA Environment does not contain POV-Ray or any part of it, rather it can run it in unmodified form as a standalone executable.
* Oasys LS-DYNA Environment software release bundle does not contain POV-Ray, users need to download and install it for themselves.

The POV-Ray home page is [http://www.povray.org/](http://www.povray.org/ "http://www.povray.org/")where you can find information about the tracer itself, its licensing, download links and also online documentation.
