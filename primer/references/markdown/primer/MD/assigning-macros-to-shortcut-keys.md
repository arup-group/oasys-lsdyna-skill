###  Assigning Macros to Shortcut Keys

Macros can be assigned to shortcut keys to make them quick and easy to run. To do this use the Assign Macros to shortcut key button (or press the shortcut key ' ? ')

Using the above button will only assign the macro to the shortcut key for this session of PRIMER. If you want to always assign the macro to a shortcut key use the primer\*F1\_key preferences etc in the shortcut\_keys branch for PRIMER in the oa\_pref preference file. Note that the preference can be used to run either a shortcut, a script or a macro. For PRIMER to know that the preference should run a macro, the macro **MUST** have the extension **prm** .
