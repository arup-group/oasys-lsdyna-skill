###  Simple Meshing Operations

| PRIMER has simple meshing capabilities. Currently you can:<br> <ul> <li> <a href="extrude.md#extrude">Extrude </a>nodes to create beams or shells, or extrude shells to create solids or thick shells. </li> <li> <a href="offset.md#offset">Offset </a>shells to create shells or solids. </li> <li>Create a <a href="ruled.md#ruled">ruled mesh </a>between two lines of nodes. </li> <li>Mesh a <a href="area.md#area">quadrilateral or triangular area </a>by giving the corner nodes. </li> <li>Create a <a href="blockbox.md#block">cuboidal solid block </a>. </li> <li>Create a <a href="plate.md#plate">rectangular shell plate </a>. </li> <li>Create a <a href="line.md#line">line of beams </a>between 2 nodes. </li> <li>Create a <a href="cylindertube.md">cylinder/tube </a>made of shells. </li> <li>Create a <a href="hemisphere.md#hemisphere">hemisphere </a>made of shells. </li> <li>Create a <a href="sphere.md#sphere">sphere </a>made of shells. </li> </ul> <br>To change the mode use the popup at the top left of the meshing panel. | ![](../Storage/primer-22-1/primer_links/sect_6/meshing/mesh_types.png) |
| --- | --- |
| For all of the meshing modes you must give a part ID for the new beams/shells/solids/thick shells to be created in.<br> <br>Additionally you have control of the numbering that is used for new nodes and new beams/shells/solids/thick shells. | ![](../Storage/primer-22-1/primer_links/sect_6/meshing/mesh_common.gif) |
| Use the popup to select which option you require.<br> <br>If you choose Start at label then give a label number to start from. PRIMER will try to use that number. If a node or beam/shell/solid already exists with that label it will revert to Highest+1 in model . | ![](../Storage/primer-22-1/primer_links/sect_5/element/split_beam_label_popup.gif) |
