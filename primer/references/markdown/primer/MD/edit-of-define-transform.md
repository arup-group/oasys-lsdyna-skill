###  Edit of Define Transform

Using the TRANID popup, you may create or edit the Define Transformation statement. Any newly created will be be placed at the top of the include file.

![](../Storage/primer-22-1/primer_links/sect_3/images/incl_trans_3.gif)

Each definition can contain multiple transformations ( the options available for which are TRANSLATE, ROTATE and SCALE . Whilst INSERT mode is selected clicking the green [+] button will add another in the row below. MOVE UP and MOVE DOWN allow the altering of the order in which the transformations are applied. A label in the TRANID filed must be defined before the CREATE\_TRANSFORMATION button will become active.
