###  The Generic KEYWORD Editing Panel

| There are many places in PRIMER where an explicit create/edit panel is not necessary, and a generic "keyword editor" will suffice. The "Keyword editor" has the additional advantage that it lists all items of a particular type, allowing multiple edits to be carried out with a single command.
<br>This is invoked by the KEYWORD tab, as shown here, from the standard options available once a selections has been made from the Keywords panel. | ![](../Storage/primer-22-1/primer_links/sect_5/5a/fig_5_0_5.gif) |
| --- | --- |

| The Keyword Editor has been completely rewritten for PRIMER release 9.3 to improve its functionality and make it easier to use. In particular:<br> <ul> <li>The separate <span class="courierbold">Edit </span>, <span class="courierbold">Insert </span>and <span class="courierbold">Delete </span>modes of the original version have been superseded, with all this functionality now available in a single operating mode. <br> <br> </li> <li>The limitation that only a single keyword sub-type could be displayed at a time has gone: it is now possible to display entities of all sub-types of a master keyword together, combining any permutation of sub-keyword suffices. <br> <br> </li> <li>Following from this it is now possible to insert, remove or change the sub-keyword suffices for the entities shown. <br> <br> </li> <li>The display and functionality of the editor have both been improved, including sorting by column and &quot;intelligent&quot; editing of data fields over multiple entries. </li> </ul> |
