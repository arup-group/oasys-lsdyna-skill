###  Group I/O

All Groups in the model may be written to an Ascii file using the **EXPORT** function. Similarly an ascii groups file may be read in using **IMPORT** . The **PART\_LIST** function writes an explicit list of all parts contained in groups to ascii file: group\_parts.asc.

You can make groups that you create in PRIMER available in D3Plot by writing a [groups file](writing-ztf-and-group-files.md#ztf).
