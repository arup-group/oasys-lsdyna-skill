###  TRANS-ROT: Translate and Rotate

| The Translate-rotate function requires the user to define a base triad and a target triad.<br> <br>Each is defined by an origin node (O) a second node prescribing the X vector (Ox) and a third node lying in the XY plane (Oy). The appropriate Y and Z vectors are then found.<br> <br>A translation vector of base origin node to target origin node and a set of rotations (base triad to target triad) have now been established.<br> <br>This translation and rotation will then be applied to the select items.<br> <br><br> ![](../Storage/primer-22-1/primer_links/sect_6/orient/fig_6_3_7.gif) |
