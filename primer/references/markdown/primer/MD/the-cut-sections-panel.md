###  The Cut Sections Panel

![](../Storage/primer-22-1/the_cut_section_panel.png)The parts of this panel are summarised below. Click on one to jump to the more detailed description.

| [Cutting switch](cutting-switch.md#cut_switch) | Normally OFF, in which case cut-sections are inactive. May be toggled on/off at any time. |
| --- | --- |
| [Direction](multiple-cuts.md#directions) | Up to 3 directions D1, D2, D3 of cut planes can be turned on/off and edited by selecting the tab. |
| [Dragging](dragging-the-cut-section.md#move_sect) | Various options for dragging the section with the mouse |
| [Definition method](definition-method.md#defn_method) | Toggles between the six different ways of creating a cut section |
| [Properties](properties-computing-cut-section-properties.md#properties) | Extracting engineering properties (Area, I, etc) of the cut elements |
| [Positive & Negative action](positive-negative-action.md#posneg) | How the +ve and -ve sides of the plane are displayed |
| [Thick cut](thick-cut.md#thick) | Optional "thick" (finite thickness) plane display |
| [Multiple cuts](multiple-cuts.md#multi) | Optional multiple parallel cutting planes |
| [Exclude Part](exclude-part.md) | Exclude individual Part/Part Sets from the cutting plane |
| [Element capping](2d-element-capping.md#cap_2d) | How the cuts through 2D elements are displayed |
| [Display Settings: Save/Retrieve](nan) | Saves cut-sections, and restores previously saved ones |
| [Display Settings: Plane display](plane-display.md#display) | Whether, and how, the actual plane itself is displayed |

&lt;&lt; Undock Undocking this panel.

From PRIMER V18 onwards the cut section panel can be undocked using to make it a "floating" panel. This enables it to be active at the same time as other tools, which can be very useful when dealing with intricate geometry. It can be redocked at any time using &gt;&gt; Dock .

If you undock it then remember that the mouse can only be active for one operation at a time, so if you need to alternate between dragging a cut section and using the mouse in some other context, eg picking, it will be necessary to swap mouse activity back and forth using the mouse activity control buttons in the top left of the respective panels:
