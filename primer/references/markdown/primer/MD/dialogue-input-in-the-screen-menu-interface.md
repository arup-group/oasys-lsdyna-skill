##  Dialogue Input in the Screen Menu Interface

A limited command-line capability (see [Appendix L](l-dialogue-typed-in-command-syntax.md)) is preserved when PRIMER is running in screen-menu mode, and you are free to mix command-line and mouse-driven input at will. These may be typed into the dialogue box:

![](../Storage/primer-22-1/primer_links/sect_2/images/fig_2_3_1.gif)

The dialogue box is also used for listing messages, warnings and errors to the screen. It can be scrolled back and forth (its buffer is 200 lines long) to review earlier messages. The following colours are used:

* Normal messages and prompts Yellow
* Text typed in by you White
* Warning messages and Error messages Red
