####  Temporarily Suspending the Transformation on an Include Transform

| Sometimes it may be useful to temporarily suspend the transformation (translation, rotation and scaling) on an include transform. This can be done by using Suspend in the Transform popup. If an include transform has previously been suspended there will be a Reinstate option instead which will reinstate the transformation data.<br> <br>This can also be done from the [part tree](part-tree-behaviour.md#part_tree_behaviour). | ![](../Storage/primer-22-1/primer_links/sect_3/images/suspend_incl_trans.png) |
