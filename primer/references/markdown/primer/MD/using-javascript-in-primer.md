##  Using JavaScript in PRIMER

JavaScripts need to be
 ***compiled***, meaning turned from something human-readable into a set of instructions that a computer can understand; and then
 ***run***in their compiled form. They can be changed and rerun in their modified form at any time without having to exit and re-enter
PRIMER
, making the "write, test, modify, re-test" development cycle very quick and easy.
