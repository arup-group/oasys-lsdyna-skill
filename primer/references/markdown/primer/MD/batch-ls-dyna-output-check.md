####  Batch Ansys LS-DYNA Output Check

The dyna output checks can be performed from the command line and in batch mode by using the syntax: : **DYNA\_OUTPUT MODEL &lt;n&gt; DYN\_OUT\_FILE &lt;filename&gt; APPLY or DYNA\_OUTPUT MODEL &lt;n&gt; APPLY.**

This command will the dyna output check and write out a summary file..
