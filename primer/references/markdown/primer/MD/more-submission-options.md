###  More Submission Options

![](../Storage/primer-22-1/primer_links/sect_3/images/fig_3_18_9.png)
The panel is launched by pressing the
**"More Options"**button on the main panel.

####  Job Options

1. **Memory** : This option is only available for the MPP/HYBRID version of Ansys LS-DYNA. 
With the MPP/HYBRID versions of Ansys LS-DYNA more memory is required for the first CPU that initialises the model than for the other processors. 
The units used to define the Memory Limit can be switched between **Words** and **Megawords**
2. **Memory2** : The value entered is the size of the main array declared internally within
Ansys LS-DYNA that is used to store data in. 
The units used to define the Memory Limit can be switched between **Words** and **Megawords**
3. **CPU Limit** : The value entered is the actual amount of CPU time that Ansys LS-DYNA will use for the analysis. 
When this limit is reached Ansys LS-DYNA will terminate the job. 
The units used to define the CPU limit can be switched between **Seconds, Minutes and Hours** . 
A value of "0" means that no limit has been set and the job will run to termination.
4. **Output Files** : This option controls the names of the output files generated by Ansys LS-DYNA, either ARUP or LSTC can be selected.
5. **CPU Consistency** : This option controls whether parallel analyses are run with the accuracy option in Ansys LS-DYNA turned ON or OFF.

####  Hybrid and Parallel Options

1. **Hybrid Options** : Available only for HYBRID LS-DYNA runs on a LINUX machine.
    * **MPP/SMP threads** : The number of MPP threads that can be selected for HYBRID jobs.
2. **Parallel Options** : This option will only be available when submitting MPP jobs.
    * **Local Host** : When selected the MPP jobs will be submitted using only the machine that the shell is being run on.
    * **Node File** :This option can be used to select a file containing a list of Nodes and CPUS to use when submitting an MPP job. 
The format of this file is given in the SHELL manual.
    * **Node List** :This option can be used to specify a string containing the list of Nodes and CPUS to use when submitting an MPP job. 
The format of this file is given in the SHELL manual.

####  Submission Type Options

The parameters that can be specified under each submission type option are different and those available under the
**Queue option**will vary from system to system.
1. **Start Time** : Specify a time at which the Ansys LS-DYNA job will execute.
    * Available for QUEUE or BACKGROUND submissions.
    * The required time should be entered in the form HH:MM using a 24-hour clock.
    * If no time is specified, then the job will be executed as soon as possible.
2. **Start Day** : Specify the day on which the job will be executed.
    * Available for QUEUE or BACKGROUND submissions.
    * If a day is specified and no analysis start time has been set, the job will be submitted with a start time of 00:01 on the required day.

#####  Options for QUEUE 
These options are available only for the QUEUE submission type. 
The options in the menus are prepared from the [**'oasys\_queue'**](configuration-of-the-tool.md#oasys_queue)
1. **Queue Name** : NQS style queue list mentioned in 'oasys\_queue'.
2. **Queue Options** : : The options available will depend on:
    * Selected Queue
    * NCPU value
    * Contents of the 'oasys\_queue' file
3. **Queue Memory** : The value entered defines the total amount of memory that the job will request from the system.
4. **Queue CPU** : The value entered is the total Queue CPU Limit that include the time taken to run the Ansys LS-DYNA analysis and any system time required.
5. **CPU Limit** : : When a queue is selected the CPU limit for that queue will be displayed.
    * If the queue is a pipe queue the word **PIPE** will be displayed
    * If the queue has no CPU limit, then the word **NONE** will be displayed
