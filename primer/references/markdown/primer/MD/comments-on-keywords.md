####  Comments on Keywords

![](../Storage/primer-22-1/primer_links/sect_5/5a/kwe_11a.png)If a keyword contains embedded comments a light blue C will be shown on its row button, and hovering the cursor over that button will list the comments on that keyword.

Comments can be added, modified and deleted using the [Text edit](changing-an-existing-definition-in-the-data-rows.md#ke_text_edit) capability.
