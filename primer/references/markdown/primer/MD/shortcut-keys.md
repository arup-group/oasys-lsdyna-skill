###  Shortcut Keys

| Some panels and actions can be accessed through pre-programmed key shortcuts, which are customizable.<br>
<br>These include the top menu panels, all the contour buttons and the Lock and Centre buttons. JavaScripts and Command Files can also be assigned to a key.<br>
<br>A listing of the available shortcuts and the keys they are assigned to can be brought up by pressing either the '?' key (by default) or accessing it through the Options top menu. | ![](../Storage/primer-22-1/primer_links/sect_2/images/invoke_shortcut.png) |

Shortcut keys are effective when the mouse is in any PRIMER window  ***except***  the dialogue box, in the latter they are interpreted as normal text input to the command-line interpreter.

There is an option to configure 3D mouse buttons through the shortcuts panel. Click on the Configure 3D SpaceMouse buttons to assign functions, macros and JavaScripts to buttons on a 3DConnexion 3D mouse. See [3D Mouse](3d-mouse.md#mouse3d) for more information on 3D mice.
