#  Images

| PRIMER can read images in as the background or watermark.<br> <br>It can also capture graphics and copy to file in four ways:<br> <ul> <li> By Laser plotting, generating a Postscript file, using the <a href="controlling-laser-plotting-using-the-laser-plotting-panel.md#plotcontrol"> <span class="buttontext">POSTSCRIPT file </span> </a>command</li> <li> By a screen grab, generating Bitmap or JPEG files, using the <a href="raster-images.md#images"> <span class="buttontext">Image file (.jpg etc) </span> </a>command</li> <li> By generating a <a href="3d-pdf.md#3DPDF">3D PDF file </a>, using the <span class="buttontext">3D PDF </span>command</li> <li> By generating a <a href="webgl.md#WebGL">WebGL file </a>(viewable in a web browser)&#160;</li> </ul> |
