####  Positioning the Headform

The figure below shows the main headform-positioning panel. This has been designed for use from top to bottom to create a run-ready input deck. A target definition must exist in the model in order to be able to position the headform. This can be created with the  [SETUP_TARGETS](setting-up-targets.md#setuptarget) button.

If multiple headform definitions exist in the model the definition to be positioned must first be selected.
