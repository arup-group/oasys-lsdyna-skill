####  Adding a 'range' row using the group editor

A new entry can be added to the group by using the ADD\_ROW button. The [ADD/REMOVE](selecting-add-or-remove.md#rangeadd)and [box](using-a-box.md#rangebox)buttons work in the same way as the [panel to add entities by list](adding-entities-by-range.md#addrange). As an example we will add the row to the group 'Remove PARTs 304 to 306 in box 2'. At present the ADD\_ROW button is inactive as there is nothing to add. Firstly, the [Add/Remove popup](selecting-add-or-remove.md#rangeadd)must be used to change the ADD button to REMOVE .

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7i.gif)

Next the to and from parts needs to be selected. You can either type the part number into the box or (as shown) use the popup menu to select the part from a list or pick it from the screen.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7j.gif)

| Once the part has been selected the from field will be filled in:<br> <br>![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7k.gif) |
| --- |

A similar process can be done to select the to and box fields. When the to and from fields are selected the ADD\_ROW button becomes live.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7l.gif)

Now to add the row to the group simply press the ADD\_ROW button. A new row '3' will be added to the list. The add row will be reset back to the default values.

![](../Storage/primer-22-1/primer_links/sect_6/groups/groups_7m.gif)

####  Editing a 'range' row using the group editor

Each of the existing rows can be modified if needed. For each row the [ADD / REMOVE](selecting-add-or-remove.md#rangeadd)and  [box](using-a-box.md#rangebox) buttons work in the same way as the [panel to add entities by list](adding-entities-by-range.md#addrange). The from and to entities can be modified by either changing the number in the text box or by using the popup menu.

To save the change into the group press END\_EDIT .

| Deleting a 'range' row using the group editor  <br>To delete an entry from a group use the Delete row? popup.
