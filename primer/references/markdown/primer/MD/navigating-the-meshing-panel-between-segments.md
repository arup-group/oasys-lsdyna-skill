####  Navigating the Meshing Panel between Segments

When a belt definition has more than one segment the meshing panel only displays one segment at a time: by default the first. In addition the segment highlighted on the display will be the current one.

| ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_4k.gif) |
| --- |

To move between segments use [&lt;] to go backwards, and [&gt;] to go forwards. You can revisit and modify segments as often as you like, they only get meshed when the GENERATE command is used.
