# Seat Part/Node Set Input

Specify the seat part sets, node sets for creating the assemblies, and the nodes required to define connections between assemblies for the Seat Slide and Height Adjustment mechanisms.

![](../Storage/primer-22-1/seat-pos-seat-part-node-set-input/seat-pos-seat-part-node-set-input-2025-04-22.png)

Select the relevant tabs to specify part/node sets and connection nodes for the **Seat Base Tilt** and **Headrest** mechanisms. Use the checkboxes to disable them if they are not relevant or not available in the input seat models.

In the Seat Base Tilt section, you’ll also need to specify the minimum and maximum tilt angles. For the Head Restraint, provide the minimum and maximum height for height adjustment, as well as the forward and rear tilt angles for fore/aft adjustment.

![](../Storage/primer-22-1/seat-pos-seat-part-node-set-input/seat-pos-seat-part-node-set-input-2025-04-22-1.png)

![](../Storage/primer-22-1/seat-pos-seat-part-node-set-input/seat-pos-seat-part-node-set-input-2025-04-22-2.png)

Click the "?" help button to learn more about the part sets and the nodes that need to be selected.

Once all the parts are selected, click Create Mechanism to create the mechanism definitions in the seat. This will redirect you to the "Mechanism and H-Points" section.
