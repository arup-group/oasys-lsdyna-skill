#### Utilities Tab

The Utilities tab is used to reset or delete morph boxes. Clicking Reset after selecting a morph box will return its morph points to their original coordinates (at the time of creating the morph box). These initial coordinates are written in the \*MORPH\_BOX keyword after \*END, hence changed morph boxes can be reset in later PRIMER sessions.

Clicking Delete will delete the selected morph box(es) with a confirmation menu, in a similar way to the Remove tool.
