###  Introduction

The HIC Area Calculator can be used to read external data files into PRIMER to plot the results from pedestrian head impact analyses. Once read the tool can be used to calculate regions of high/low HIC - a legal test requirement - as well as NCAP scores.

The tool also contains additional functionality to help you interpret the results, identify areas of sensitivity and interact with pedestrian head impact analyses.
