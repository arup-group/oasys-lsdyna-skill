###  Changing the Order of Columns

The order of the columns can be changed by clicking on a column header and dragging the column left or right to a new location. When you are at a valid location the cursor will be a + symbol and when you are at an invalid location the cursor will be a X symbol. E.g. below the user has clicked on Part title and has started dragging the column. If they wanted to move the column to be between the Gauge and Mat ID columns they would drag the header until the cursor symbol changed to + between the 2 columns.
