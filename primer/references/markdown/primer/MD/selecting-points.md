###  Selecting Points

You can select points by using the point of interest tool, impact list and shift clicking an area.

####  Point of interest 
 
You can use the point of interest tool to select an area. After clicking the update button all the points encapsulated in that area will be selected. 
To do this you first need to enter in the coordinates of a central point and then selecting if you want the area to be a strip in the X and/or Y direction or a radius around the specified central point.

You can shift-select points to select all the points in-between the initial and end point.
