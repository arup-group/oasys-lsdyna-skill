##  Databases: Importing Data from Pre-Defined Database Files

 * Database files allow you to access predefined data of any type. Typical uses are material, section and loadcurve data; but anything which can be stored in tabular form may be accessed in this way.

The format of databases in PRIMER is described in [Appendix I](i-primer-database-format.md).
