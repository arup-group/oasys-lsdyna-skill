### DEFINE: Defining Define Options
 The \* **DEFINE** keyword in Ansys LS-DYNA is used to define various things including boxes, load curves, tables, coordinate systems and orientation vectors. 

| The main **DEFINE** pop-up menuallows any of the sub-categories to be selected. After a category has been selected a separate menu will be displayed allowing items to be created, modified and deleted. <br>Some **DEFINE** keywords are edited in PRIMER using the [generic Keyword editor](the-generic-keyword-editing-panel.md#keywordedit).
