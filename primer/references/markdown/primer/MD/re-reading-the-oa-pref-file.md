####  Re-reading the "oa_pref" file

It is not needed to quit and restart PRIMER to return your settings to the state they are in on initial start up.

PRIMER can restore settings to their default value and re-read the system and home oa\_pref files using the feature Reset PRIMER Prefs or Reread PRIMER Prefs . It is available from the main Options drop-down and under CHECK &gt; OPTIONS.
