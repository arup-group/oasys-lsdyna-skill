###  Storing and Retrieving Properties
 
![](../Storage/primer-22-1/primer_links/sect_9/images/fig_9_0b.png)

The Save P button and the two arrow buttons below it allow you to save "properties", which are the current viewing attributes, and then cycle backwards and forwards between saved properties. A "property" includes any permutation of colour, transparency, display mode, blanking, entity switches and current view - all the factors which control the appearance of the image on the screen. Properties may be saved to property files (.prp) and reloaded at any time, and these files are portable between different Oasys LS-DYNA Environment programs.
