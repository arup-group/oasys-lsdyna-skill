###  Reading Ansys LS-DYNA Output Error Files

It is possible to interrogate the output files produced when Ansys LS-DYNA is run for errors and warnings and display the associated entities within. 
You can either "**Initialise**" the model in Ansys LS-DYNA and interrogate the Ansys LS-DYNA results directly or load the "**Existing**" Ansys LS-DYNA results. 
This functionality is accessed by clicking the LS-DYNA button
