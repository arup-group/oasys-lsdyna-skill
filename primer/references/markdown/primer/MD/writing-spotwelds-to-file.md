###  Writing Spotwelds to File

| This panel allows you to write mesh independent spotwelds to a [PRIMER spotweld file](primer-spotweld-file-format.md#format), an [XML connection file](primer-xml-connection-file.md#xmlfileformat), a [UG weld file,](ug-spotweld-file-format.md#ug_format)an IGES file or a [Master Connection File](master-connection-file-mcf-format.md#mcf_format). Select which file type using the lower radio button selection.<br> <br>The XML file also supports the export of bolts and adhesive connections.<br> <br>When choosing the IGES option, adhesive connections are written as IGES lines. All other connection types are written as IGES points.<br> <br>You can specify which connections to write by a number of different methods. For more details of the different methods see .<br> <br>Type in the name of the file you want to write or use the file selector button.<br> <br>Once you have specified the filename, which connections you want to write and the file format press the Apply button to write the file.<br> <br>A script can also be used to write connection data out in a user defined format. The user would create a JavaScript that would write connection data in the format desired, and then this script can be used through the connection write panel to write the connections in that format. See [Scripting](introduction.md) for more on PRIMER's scripting functionality. | ![](../Storage/primer-22-1/primer_links/sect_6/connection/write_weld_1.gif) |
