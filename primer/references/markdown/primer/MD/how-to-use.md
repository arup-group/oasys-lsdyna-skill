###  How to Use

Navigate to Tools &gt; Safety &gt; Pedestrian &gt; Pedestrian run builder. You will be asked to give a list file as an input. 
 
After reading in a list file, the main window will appear. You will choose the include filename that you wish to change and use the grid of impact points to select and deselect different points interactively. The grid of points is constructed from the information in the list file.

After you've chosen the points, you can click generate, which will ask you for a new directory name. The tool will make copies of the original models for the points selected in the new directory and update the include references according to the information provided on the panel.
