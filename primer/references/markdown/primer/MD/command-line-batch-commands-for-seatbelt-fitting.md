###  Command-Line (Batch) Commands for Seatbelt Fitting

A limited subset of the operations described above can be performed in command-line mode. These are intended to permit batch mode refitting of an existing belt definition, and they also include the ability to modify some aspects of belt geometry and fitting.

| BELT | Refit an existing seatbelt to a dummy. PRIMER will select a seatbelt definition in the model automatically. Available options are:<br> <br><br>| SELECT | Select a different belt definition for refitting |<br>| --- | --- |<br>| REFIT | Refits the current belt definition to its dummy |<br>| PR\_BASIC | Retrieve and update basic belt dimensions and form-finding parameters |<br>| PR\_REFIT | Retrieve and update belt refit parameters |<br>| DONE | To return to the main menu prompt | |
