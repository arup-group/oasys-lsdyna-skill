###  Graticule

| This can be used to display the current model dimensions.<br>
<br>The graticule can be drawn in either 2D or 3D.<br>
<br>The format of the numbers on the graticule can be set automatically by PRIMER or you can manually select the number of decimal places and the exponent value to display.<br>
<br>The line and text colours can be modified if necessary. | ![](../Storage/primer-22-1/primer_links/sect_4/images/fig_4_1_4.png) |
