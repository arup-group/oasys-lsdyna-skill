####  Batch Error Check and Autofix

Checking may be called from the command line using the syntax: **CHECK MODEL &lt;n&gt; CHECKFILE &lt;filename&gt; APPLY** or **CHECK MODEL &lt;n&gt; APPLY.**

You may include the option **FULL\_LIST** if you want a detailed listing of every item label in the file, otherwise labels will not be printed for the more populous items types (such as nodes and elements).

Similarly the Autofix all function may be called in command line using the syntax **AUTOFIX MODEL &lt;n&gt; APPLY** .
