#####  Choose as Few Points as Possible for Each Path Segment

| In this example the advice has been taken too literally!<br>
<br>A point has been chosen on the shoulder, and another on the abdomen, but the path between then fails to clear the bulge of the upper chest.<br>
<br>If this was fitted part of the belt would get stuck "inside" the chest shells.<br>
<br>The problem could be solved in two ways: either by increasing the initial distance by which the belt is projected outwards prior to fitting (which would be an inefficient solution), or by adding an extra point.<br> ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_2x.gif) |
| --- |
| Here the problem has been solved by adding an extra point on the upper chest to force the belt path clear of the dummy.<br> <br>(This is more efficient than increasing the projection distance since fewer form-finding iterations will be required to pull the path back into contact with the dummy.)<br> <br>However the principle of using as few points as possible to define the belt path is correct as it will give a simpler and smoother path, as well as reducing the likelihood of reverse curvature. (As with approximating functions with polynomials, a lower order equation will give a smoother, if less precise, fit.)<br> <br>Remember that the initial path does not have to adhere exactly to the dummy's contours: a simpler and looser shape will work just as well as it will be pulled back onto the dummy surface by the form-finding process.<br> ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fig_7_2_3_2y.gif) |
