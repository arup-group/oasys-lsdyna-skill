####  CT Plot of Shell Normals

There are 2 sub options Contour and Vector available for shell normals CT/SI plot.

The Contour sub option colors shells pink or blue depending on which direction the normal points to(Towards or Away from the user). The Vector sub option draws as arrow on the shell centroid pointing in the same direction as the shell normal.
