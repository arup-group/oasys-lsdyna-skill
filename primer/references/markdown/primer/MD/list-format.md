###  List Format 
 A list file is a text file containing a list of all the impact points and original model locations. This file is produced by PRIMER 's model build/mark-up capabilities but can be produced outside of PRIMER as well. 
 
The list file format required is as follows: 
$variables, XCOORD, YCOORD, ZCOORD 
FILENAME, xcoord\_value, ycoord\_value, zcoord\_value
