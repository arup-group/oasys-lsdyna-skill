##  Setting the theme

The default software theme in Oasys 22.1 is **Light**. This can be changed from the Oasys SHELL by choosing from the Themes pop-up. This automatically saves the selected theme as your preference for all programs.

![](../Storage/primer-22-1/project-common-topics/setting-the-theme/setting-the-theme-2025-06-12.png)

The theme can also be set for individual programs from the Display menu in PRIMER, D3PLOT and T/HIS or the Preferences menu (File-&gt;Preferences...) in REPORTER. This choice is not automatically retained after exiting the program, so you must select a theme, then select Save pref to ensure a theme is used for all future sessions.
