###  Ansys LS-DYNA Submission Tool

* This tool allows you to easily submit a model into Ansys LS-DYNA directly from PRIMER.
* The model can be submitted locally or onto a remote machine/cluster.
* As well as speeding up the submission process, the functionality allows easy initialisation and model checking with a few clicks.
* To aid the above, this functionality has been integrated with the [**"Ansys LS-DYNA Output Reader"**](reading-ls-dyna-output-error-files.md#readdyna)****tool in PRIMER. 
This is to speed up the process of initialisation when checking models and visualising decomposition/load profiles.
* This tool uses functionality that exists within the SHELL submission tool.

![](../Storage/primer-22-1/primer_links/sect_3/images/fig_3_18_1.png)

####  Purpose 

* This tool can be accessed by clicking the **Model-&gt;Submit** button to perform Ansys LS-DYNA runs directly from PRIMER.
* **"Local" machine** : The same Windows or the Linux machine from where the PRIMER session is launched.
* **"Remote" machine** : Linux machine on a network where Ansys LS-DYNA is configured to run.
* You can also monitor the progress of **"ONLINE"** (real time) Ansys LS-DYNA runs on a "Local" machine.
* You can perform Ansys LS-DYNA initialisation of the model in a PRIMER session and view Ansys LS-DYNA results via the [**"Ansys LS-DYNA Output Reader"**](reading-ls-dyna-output-error-files.md#readdyna)****tool in PRIMER.
