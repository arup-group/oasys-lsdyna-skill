###  24-Bit File Formats

| | BMP | Uncompressed 24 bit Microsoft windows bitmap. The approximate size of the file (in bytes) is file size = 3 \* image width \*image height |<br>| --- | --- |<br>| PNG | 24 bit lossless compressed **P**ortable **N**etwork **G**raphics image. offers the similar degree of compression as GIF but has better colour quality. |<br>| JPG | Joint Photographic Experts Group compressed format. This gives image quality nearly comparable to 24 bit-plane bitmaps, but with a file of &lt; 5% the equivalent size. JPEG format is supported by all common visualisation packages and is recommended for all applications unless image quality is of paramount importance. |<br>| PPM | 24 bit uncompressed Portable Pix Map. The approximate size of the file is [3 \* image width \*image height] bytes. |<br><br><br><br>![](../Storage/primer-22-1/primer_links/sect_8/images/fig_6_9c.png) |
