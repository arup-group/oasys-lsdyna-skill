###  Tuning 3D Mouse Behaviour

| The 3DCONNEXION install package comes with a tuning panel that controls many aspects of the device, but it is also possible to adjust PRIMER 's use of it via the Display &gt; Tuning panel.<br>
<br>This allows the speed of response to 3D mouse movement to be adjusted: values &gt; 1.0 will speed up response, and &lt; 1.0 will slow it down. | ![](../Storage/primer-22-1/primer_links/sect_9/images/tune_1.png) |
| --- | --- |
| | Rotation speed factor | Controls the speed of response in all three rotational degrees of freedom |<br>| --- | --- |<br>| Pan speed factor | Controls the speed of response to left/right and up/down "panning" in the plane of the screen |<br>| Zoom speed factor | Controls the speed of response to in/out panning - tantamount to scale changes in non-perspective projection. | | ![](../Storage/primer-22-1/primer_links/sect_9/images/tune_3.png) |
