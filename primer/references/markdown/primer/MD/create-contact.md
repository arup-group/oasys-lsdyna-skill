###  Create Contact

Select "create \*AUTO\_SINGLE\_SURFACE contact"option as shown below to create a \*CONTACT\_AUTOMATIC\_SINGLE\_SURFACE with an exempted part set on the SURFA side. Impactor parts will be added automatically to the exempted part set. Use "Exempted part set" option to add any other part sets to the exempted set.
