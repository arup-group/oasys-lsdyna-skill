##  Implicit Setup Tool

The Implicit Setup Tool can be used to help setup the \*CONTROL cards required for running various implicit analyses. The tool is accessible from the Implicit button in the Tools panel. Ideally, the tool should be used when the current model does not already contain any \*CONTROL\_IMPLICIT\_... keywords, however there are options to control how the tool behaves when the model does. Note that this tool does not create any loads, boundary constraints, etc. that may be needed for the analysis, these must be setup outside of the tool.
