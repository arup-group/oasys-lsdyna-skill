##  LOAD PATHS

The LOAD PATH panel allows you to create LOADPATHs joining the centres of \*DATABASE\_CROSS\_SECTION definitions. They can then be viewed in D3PLOT if a ZTF file is generated. Forces calculated from the \*DATABASE\_CROSS\_SECTIONs can be plotted on the LOADPATHs to make visualisation of loads through a structure easier.

This tool can also be used to auto-create multiple \*DATABASE\_CROSS\_SECTION definitions across a desired structure.
