##  Current Limitations

The following limitations apply to buttons that can be added to your Favourites menu:

* Favourite Tools can contain any button from the core Tools tab, apart from the buttons Other, Safety, FMH and Pedestrian. However, sub-tools from these buttons can be added (e.g. the HIC Area Calculator or Dummy Finger Positioning tools)
* Custom popups can be created. For example, buttons can be listed under a top-level button carrying, say, a company name. However, only 1 hierarchy level is permitted for such popups.​
