####  The Advanced Editor Mode

The "advanced" editor mode has been introduced to make it easier to fit belts around difficult geometries, and also to make creation of fully meshed belts easier. It can be used for "simple" belts as well, and you can swap between basic and advanced modes by ticking/unticking the [ ] Advanced button.

The main difference that you will see is in the image of the belt itself where much more functionality has been given to the mouse. The belt editor panel itself is largely unchanged.
