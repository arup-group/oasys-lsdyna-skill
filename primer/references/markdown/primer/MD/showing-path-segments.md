#####  Showing (Path Segments)

| Controls whether the complete belt path is drawn, or only a single segment of it.<br><br>![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fopts_showing_1.png) |
| --- |
| **All segments**is the default case, in which the whole belt path is drawn.<br> <br>When defining a path for complex geometries, such as the detail around the "wing" of the child seat shown here, it can sometimes help if only the segment of interest is shown, since other segments may get in the way.<br> ![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fopts_showing_2.png) |
| Showing **Only**one segment, here the first one, can make it easier to see what you are doing.<br><br><br>![](../Storage/primer-22-1/primer_links/sect_6/seatbelt/fopts_showing_3.png) |
