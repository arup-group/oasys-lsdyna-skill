# Seat Model Input

Select a seat model and specify the Seat Type, Vehicle Direction, and SGRP-Point (R-point). Selecting a seat type (FRONT\_RIGHT or FRONT\_LEFT) allows the tool to assign different mechanism IDs to each seat, preventing conflicts when multiple seats are positioned within the vehicle.

The tool assumes that the seat will initially be positioned at the R-point when loaded.

Next, select the manufacturer's design position for the various assemblies required by the regulation.

Specify the default initial positions for the seat back angle, seat base tilt, and head restraint height to be applied when the model is loaded.

![](../Storage/primer-22-1/seat-pos-seat-model-input/seat-pos-seat-model-input-2025-04-22.png)

Once all the inputs are provided, Seat Part Set Input&gt;&gt; gets activated. Click it to proceed to the next panel.
