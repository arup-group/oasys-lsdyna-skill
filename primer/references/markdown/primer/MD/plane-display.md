###  Plane Display

![](../Storage/primer-22-1/primer_links/sect_6/cutsect/fig_14.gif)Whether, and how, the actual plane definition itself is displayed. By default plane display if Off and it is not shown. However it is possible to draw the plane in one of two modes:

| Wireframe<br> <br>Draws the plane boundaries and a diagonal as a wireframe overlay on the plot | ![](../Storage/primer-22-1/primer_links/sect_6/cutsect/demo_5.jpg) |
| --- | --- |
| Transparent<br> <br>Draws the plane as a partially transparent square, occupying model space and intersecting the structure. | ![](../Storage/primer-22-1/primer_links/sect_6/cutsect/demo_7.jpg) |
