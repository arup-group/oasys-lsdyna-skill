##  Ansys LS-DYNA Manual

If the installation of the Oasys LS-DYNA Environment software has the $OA\_INSTALL/manuals/lsdyna/keywords.txt file it is also possible to search for a keyword and open the Ansys LS-DYNA PDF manual at the appropriate page. This should be the case in a full installation.

For example, to open the manual at the \*BOUNDARY\_PRESCRIBED\_MOTION page you could type 'bprmman':
