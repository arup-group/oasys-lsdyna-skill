###  Introduction

This tool reads LSTC dummy models and converts the tree file to PRIMER format.
 
The LSTC dummy conversion tool can be accessed through the Safety button from the PRIMER Tools panel.
 
This brings up the menu in a pop up window as shown below.

![](../Storage/primer-22-1/Manual%20image%20-%20LSTC%20Conversion%20tool.jpg)

**Select** Chooses the file you want to convert.

**Apply** Runs the conversion with the current settings and file selected.

**Cancel** Exits the tool.

**Check JOINT\_STIFFNESS part order and reorder if required:** If order of parts in the joint stiffness definition does not match the created assembly structure the parts are reordered

**Use Local Coordinate System if present:** Some dummy models have both a H-point defined and a Local Coordinate System (LCS). When clicked it will use the LCS for the H-point of the dummy in PRIMER.
